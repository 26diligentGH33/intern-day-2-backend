# intern-day-2-backend

登录练习项目的后端：FastAPI + SQLite，提供账号登录鉴权与待办清单接口。

## 功能范围

- 必做：账号密码登录、获取当前用户、退出登录
- 自选功能：待办清单（新增 / 勾选完成 / 删除），数据按用户隔离

## 接口约定

| 方法 | 路径 | 需要登录 | 说明 |
| --- | --- | --- | --- |
| GET | /health | 否 | 健康检查 |
| POST | /auth/login | 否 | 登录，返回访问令牌 |
| GET | /auth/me | 是 | 获取当前登录用户 |
| POST | /auth/logout | 是 | 退出登录，令牌立即失效 |
| GET | /todos | 是 | 查询我的待办 |
| POST | /todos | 是 | 新增待办 |
| PATCH | /todos/{id} | 是 | 修改完成状态 |
| DELETE | /todos/{id} | 是 | 删除待办 |

## 登录状态怎么实现的

- 密码用 **bcrypt 加盐哈希**存库，代码里没有任何明文密码的落库路径。
- 登录成功后返回一个 **32 字节随机令牌**（不透明字符串，不含用户信息）。
- 数据库里只存令牌的 **sha256 摘要**和过期时间，即使库被读走也拿不到可用凭证。
- 退出登录 = 删除会话行，旧令牌下一次请求就查不到，自然 401。
- 所有受保护接口走同一个依赖 `app/deps.py::get_auth`，校验顺序是：请求头格式 → 令牌是否存在 → 是否过期。四种失败一律返回同一句 `登录状态无效或已过期,请重新登录`。
- 账号不存在和密码错误返回同一句 `账号或密码错误`，避免账号枚举。
- 前端的路由保护只是体验优化，**真正的门在后端**。

## 数据保存

SQLite 文件，默认 `data/app.db`，容器里通过挂载的工作目录持久化。路径可用 `DATABASE_PATH` 改。

配置项：

| 环境变量 | 默认值 | 说明 |
| --- | --- | --- |
| `DATABASE_PATH` | `data/app.db` | 数据库文件位置 |
| `SESSION_TTL_MINUTES` | `480` | 登录有效期（分钟） |
| `CORS_ORIGINS` | `http://localhost:5173,http://127.0.0.1:5173` | 允许的前端来源 |
| `SEED_DEMO_DATA` | `true` | 启动时是否补种练习账号 |

## 练习账号

全部是虚构数据，仅用于本地练习：

| 账号 | 密码 | 显示名 |
| --- | --- | --- |
| alice | `Passw0rd!2027` | Alice 的练习空间 |
| bob | `Passw0rd!2027` | Bob 的练习空间 |

初始化：`uv run python -m app.seed`（启动时也会自动补种，库空才写）。

## 运行

```bash
uv sync
uv run python -m app.seed
uv run uvicorn app.main:app --host 0.0.0.0 --port 8000 --reload
```

接口文档：<http://localhost:8000/docs>

## 已知问题与限制

- 开发容器是用 `docker build` + `docker run` 手动起的，没用 VS Code 的 `Reopen in Container`（本机 VS Code 从 Windows 侧调 docker 会失败），效果等价：工作目录挂载到 `/workspaces/intern-day-2-backend`，容器内有 uv 和 Python 3.12。
- SQLite 适合练习，并发写入有锁；真实项目应换 PostgreSQL。
- 没有做刷新令牌（refresh token），令牌过期就要重新登录。
- 暂未写自动化测试，验收靠上表的真实请求记录。

## 5 分钟演示脚本

1. 打开 <http://localhost:5173>，未登录会自动跳到 `/login`
2. 空表单直接提交 → 前端拦截提示必填
3. `alice` + 错误密码 → 「账号或密码错误」（账号不存在也是同一句，防枚举）
4. `alice` / `Passw0rd!2027` → 进入待办页，看到 3 条种子待办
5. 新增、勾选、删除各来一次，刷新页面确认已落库
6. 点退出登录，再直接访问根路径 → 又被弹回 `/login`
7. 打开 <http://localhost:8000/docs>，不带令牌调 `GET /api/todos` → 401

> 登录态真正的门在后端：`app/deps.py::get_auth` 统一校验令牌，前端路由保护只是体验优化。
